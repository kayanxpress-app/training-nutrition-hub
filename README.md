# Training Nutrition Hub — د. محمود جمال (المرحلة ١)

تطبيق ويب ثابت (من غير build). الدخول والبيانات والصور على Supabase، والنشر على Vercel من GitHub.

## الخطوات
1. **Supabase:** مشروع جديد منفصل عن الماركت بليس ← SQL Editor ← شغّل `supabase/schema.sql` (فيه الجداول والصلاحيات وتخزين الصور).
2. **Authentication → Users → Add user:** اعمل حساب لنفسك (Auto Confirm). بعدها شغّل `supabase/make_admin.sql` بإيميلك.
3. اعمل حساب لكل عميل بنفس الطريقة. 
4. **config.js:** ضع Project URL وanon key من Project Settings → API.
5. **GitHub:** repository جديد وارفع كل الملفات (محتويات المجلد).
6. **Vercel:** Add New Project ← اختر الـ repository ← Deploy (بدون build command).

## استخدام الأدمن
ادخل بإيميلك: هتظهر قائمة العملاء. افتح أي عميل وهتلاقي أزرار «تعديل» و«+ إضافة» في كل قسم (تدريب، تغذية، مكملات): اسم، لينك يوتيوب، صورة. وزرار «برنامج شهر جديد» بينسخ الحالي.

## ملفات PDF
داخل كل قسم (التدريب / التغذية / المكملات) زرار «+ إضافة ملف PDF» للأدمن. الملفات خاصة: كل عميل يفتح ملفاته فقط. لو شغّلت schema.sql قبل كده، شغّل آخر جزء فيه (ملفات PDF) بس.

## استيراد برنامج من PDF (تلقائي)
افتح عميل ← «استيراد برنامج من ملف PDF» ← اختر الملف والتاريخ. التطبيق بيقرأ الملف ويوزّع التدريب والتغذية والمكملات في أقسامها بنفس تفاصيل الملف (واللينكات).
مطلوب مرة واحدة في Vercel ← Settings ← Environment Variables:
- `ANTHROPIC_API_KEY` (من console.anthropic.com، الاستخدام بالدفع حسب الطلب)
- `SUPABASE_URL` و`SUPABASE_ANON_KEY` (نفس قيم config.js)
بعد الاستيراد راجع البيانات: كل عنصر فيه «تعديل».

## طريقة العمل اليومية
1. افتح العميل ← «+ إنشاء برنامج جديد» (أو نسخ من الشهر السابق).
2. ابني التدريب (جلسات وتمارين وفيديوهات)، والتغذية (بيانات وطاقة ووجبات)، والمكملات (صور ولينكات) بأزرار «+ إضافة» و«تعديل».
3. اضغط «نشر البرنامج للعميل»، وقتها بس يظهر له. قبل كده يفضل مسودة.
